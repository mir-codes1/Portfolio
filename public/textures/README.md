# Textures

Download the following CC0 textures from https://polyhaven.com and place them here:

| Filename | Poly Haven asset | Map type |
|----------|-----------------|----------|
| `sandstone_diffuse.png` | Any sandstone/stone texture | Diffuse/Albedo (512×512) |
| `sandstone_normal.png` | Same asset | Normal (512×512) |
| `sandstone_ao.png` | Same asset | Ambient Occlusion (512×512) |

**Suggested search:** "sandstone" or "aerial_rocks" on polyhaven.com — choose a set that
includes diffuse, normal, and AO maps.

If these files are absent, the app falls back to a procedurally-generated sandstone texture.
